# 🏥 Hospital Patient Data Analysis

## Project Description

A beginner-friendly data analytics project that analyzes hospital patient records to identify trends in demographics, departments, diseases, length of stay, and treatment costs using Python.

---

## 📂 README.md

### Overview

This project uses Python to analyze hospital patient data and extract useful insights through data cleaning, analysis, and visualization.

### Tools Used

* Python
* Pandas
* NumPy
* Matplotlib

### Key Analysis

* Age and gender distribution
* Department-wise patient count
* Disease trends
* Length of stay and treatment cost

### How to Run

Install required libraries and run the Python script or notebook.

### Note

Dataset is synthetic/anonymized and used for educational purposes only.
